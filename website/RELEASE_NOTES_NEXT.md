# Release notes for the NEXT build.
# One bullet per line. Lines starting with # are ignored.
# These become the changelog entry when the installer is built.

The set tempo can travel. Instead of averaging your records into one tempo nobody asked for, a set can now meet each pair at their own midpoint and walk the tempo between them — every record plays nearer its own speed, so there is less stretch to hear and fewer records turned away. A 129 BPM record that needed 8.5% to reach a fixed 140 now needs about 2%.
The tempo only ever moves while a record is playing alone, never across a blend, and it spreads the move across that whole stretch — the same change over five minutes instead of one, so at no point is a record pulled hard.
A blend over a quiet floor is now reported rather than refused. Dropping those joins was quietly cutting sets short: one record whose outro ends 34 seconds before its last sample took a 14-track set down to 4.
Warped clips land on the beat. The time-stretcher was placing transients up to 10 ms early, by an amount that shifted with the tempo, so two decks stretched by different amounts could sit milliseconds apart and flam on the kick. That offset is now measured and corrected.
AAC and M4A tracks play, draw a waveform and render.
Library scans no longer freeze partway through, and a scan now saves each track as it is analyzed — a client timeout or a dropped network drive no longer throws away hours of completed analysis.

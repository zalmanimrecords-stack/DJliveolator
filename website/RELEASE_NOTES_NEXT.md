# Release notes for the NEXT build.
# One bullet per line. Lines starting with # are ignored.
# These become the changelog entry when the installer is built.
- New on the mixer: AUTO crossfade. Press AUTO and the crossfader travels to the other deck over MIX SEC - anywhere from 0 to 20 seconds, 10 by default, and 0 is an instant cut. Press AUTO again to stop it where it is, or move the on-screen crossfader to take over; a hardware crossfader takes over once it passes the new position, so the mix never jumps back.
- AUTO will not fade into silence: if the deck it would fade into is not playing, the button flashes red and the crossfader stays put.
- MIX SEC is remembered between sessions.
- Hot cue pads are easier to read: an empty pad has a red outline, a stored cue lights green, and the number is bigger and bolder. Pressing a pad no longer leaves it looking stuck down.
- DJ PRO puts FX, hot cues, loop, sync and track browsing above each deck, and the deck sizes to its content.
- LIVE now shows only the visuals; the decks and mixer live on DJ PRO.
- Stem separation is switched off for now while it is made reliable.

BASS_AAC LICENSE (Sebastian Andersson / Nero AG) — summary
----------------------------------------------------------
bass_aac is a third-party BASS add-on, not un4seen code, so the BASS license
above does not cover it. Its readme states it is "free to use and distribute
as long as you follow the guidelines of the GPL", and the distribution ships
the GPL version 2 text; commercial use is directed to Nero AG at
Mpeg4AAClicense@nero.com. Separately, the AAC format itself is patent-
encumbered and licensed through Via LA (https://www.via-la.com/licensing-2/aac/).

Two consequences for shipping:
  * bass_aac is fetched by scripts/fetch-bass and IS bundled in the Windows
    installer payload, so this is distribution, not merely local use.
  * Liveolator's open-source plan is GPLv3. The bass_aac readme says only
    "the GPL" and ships the v2 text without an explicit "or any later
    version" grant, so GPLv2-only vs GPLv3 compatibility is an open question
    for the owner to settle (alongside the BASS linking exception the
    proprietary un4seen libraries already need). On Windows, macOS and iOS,
    core BASS decodes AAC/MP4 through the OS codecs, so dropping bass_aac on
    those platforms is a viable fallback if the answer is no.

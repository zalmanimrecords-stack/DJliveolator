# Archive

Point-in-time reviews, QA sweeps, roadmaps and status snapshots that were accurate when written and
have since been overtaken by the code.

**Nothing in this directory is current, and nothing here is maintained.** Each file keeps its
original content with a dated banner on top. They are kept because they record how decisions were
reached, not what is true now.

Current documentation lives in [`docs/core-business-logic/`](../core-business-logic/00-project-context.md).
The subsystem design documents in [`docs/`](../README.md) remain the record of *why* each subsystem is
shaped the way it is.

Why each file was archived, and where its surviving content went, is recorded in
[`07-doc-inventory-and-status.md`](../core-business-logic/07-doc-inventory-and-status.md).

Links inside archived files point at paths as they were before archiving and are not repaired.
